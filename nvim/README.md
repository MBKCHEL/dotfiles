# MBKCHELvim 

Minimalist, blazingly fast Neovim configuration built for Rust and other pogramming development.

## 🚀 Features
- **LSP**: Native Neovim 0.11+ `vim.lsp.config` with `rust-analyzer` & `clippy`
- **Completion**: `nvim-cmp` with LSP, buffer, and path sources
- **Explorer**: `neo-tree.nvim` with auto-focus and Git integration
- **Terminal**: Floating `toggleterm.nvim` mapped to `<C-t>` / `<C-/>`
- **Autopairs**: `nvim-autopairs` for brackets & auto-closing
- **Theme**: Catppuccin Mocha
